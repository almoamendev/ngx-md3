Elevation

Elevation separates surfaces along the z-axis. md-elevation.scss defines {{ total }} shadow tokens, each a complete box-shadow value ready to be assigned as-is — unlike the color tokens, these need no wrapping.

Each token stacks three shadow layers at different opacities to approximate a key light and an ambient light, which is what gives the shadow its soft falloff. All three layers are built from --md-scheme-shadow, so changing that one color role restyles every elevation level at once.

Levels

Note that 0dp is a zero-size shadow rather than none. That is deliberate: box-shadow only animates between values with matching layer counts, so keeping a real three-layer value at rest lets a surface transition smoothly into and out of any raised level.

Sizes are expressed in em, so a shadow scales with the font size of the element it is applied to rather than staying fixed in pixels. Offsets stay vertical in both text directions, so these tokens need no RTL handling.
