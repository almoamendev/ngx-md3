Typography

The type scale is a set of styles that can be applied to any element via a directive: [md3-type-display], [md3-type-headline], [md3-type-title], [md3-type-body], and [md3-type-label]. Each takes a large, medium, or small size, and can be further customized with the emphasized and color attributes.

API

Name Type Default
md3-type-display

Applies the display type scale.

 input<TextSize> large
md3-type-headline

Applies the headline type scale.

 input<TextSize> large
md3-type-title

Applies the title type scale.

 input<TextSize> large
md3-type-body

Applies the body type scale.

 input<TextSize> large
md3-type-label

Applies the label type scale.

 input<TextSize> large
color

Shared by all 5 directives. Sets the text color.

 input<TextColor> inherit
emphasized

Shared by all 5 directives. Increases the font weight. Plain boolean attribute, not a directive input.
  • Every directive can be applied to any element, not just headings — pick the tag for its semantics and the type scale directive for its style.
  • size and color must be set as plain string attributes (e.g. size="small", color="on-primary", [attr.size]="size?", [attr.color]="color?", [attr.emphasized]="emphasized?"), not property bindings. The directives don't reflect their inputs back onto the element — styling is applied entirely through CSS attribute selectors matching the literal attribute value.
  • emphasized has no backing directive at all; it's a plain boolean attribute matched directly by CSS.
  • Text color defaults to inherit (the parent's color) until a color attribute is set.
