API

Name Type Default
size

Shared by all 5 directives. Sets the text size.

 input<TextSize | 'default'> large
color

Shared by all 5 directives. Sets the text color.

 input<TextColor | 'default'> inherit
emphasized

Shared by all 5 directives. Increases the font weight.

 input<boolean> false
  • Every directive can be applied to any element, not just headings — pick the tag for its semantics and the type scale directive for its style.
  • size, color, and emphasized are real directive inputs — use plain string attributes (size="small") or property bindings ([size]="scale()") interchangeably, both work reactively.
  • Internally each input toggles a CSS class on the host element (md3-text-large, md3-color-on-primary, md3-emphasized) rather than being read directly by CSS attribute selectors — styling still lives entirely in md3.scss, just keyed off class names instead of attribute values.
  • size and color default to the literal string 'default' rather than one of the real size/color values. Since no CSS rule matches .md3-text-default, an unset size renders the same as size="large" (the base class already matches the large variant's font-size/line-height); an unset color renders inherit (the parent's color).
