Shape

Shape tokens are the corner radii used across the library, defined in md-border-radius.scss. There are {{ total }} of them, and each holds a complete length value that can be assigned directly.

Scale

Values are in em, not px or rem, so a radius scales with the font size of the element it is applied to. A button rendered at a larger size gets a proportionally larger corner without needing a different token — which is how one scale covers every component size.

The two -i entries are "increased" steps that sit between the named sizes, giving 20dp and 32dp without adding another name to the main scale.

--md-border-radius-rounded is calc(100vh + 100vw) rather than a percentage or a large fixed value. CSS clamps a radius that exceeds half the element's size, so any value guaranteed to be bigger than the viewport resolves to a perfect pill on a wide element and a perfect circle on a square one — without the distortion that border-radius: 50% produces on non-square elements.
