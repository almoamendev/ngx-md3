Grid

md-grid.scss defines the {{ total }} tokens behind the responsive layout grid. Unlike every other token family, these are redeclared inside media queries, so their values change with the viewport rather than with the color scheme.

Tokens

Your window is currently {{ layout.widthClass() }}, so the values below are the ones in effect for that size class. Resize the window and they update in place.

The breakpoints mirror LayoutService.widthClass(), which is what every responsive component in the library reads. The two are kept in sync deliberately: a component that switches layout at expanded and a grid that adds columns at the same point stay aligned, so nothing reflows in two stages.

Using them directly

The md3-grid directive consumes these tokens for you and is the usual way to lay out a page. Read them yourself when you need grid-aligned spacing outside a grid container — matching a section's horizontal padding to the grid margin, for instance.

Because they are ordinary custom properties, overriding them on a container rescopes the grid for that subtree only. Redeclaring them at :root after importing md3.scss changes the grid globally, though the breakpoints themselves are fixed unless you also replace the media queries.
