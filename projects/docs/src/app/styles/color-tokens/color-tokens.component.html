Color

The color scheme is {{ total }} roles defined in md-scheme.scss. Roles are named for their job rather than their hue, so a component asks for "primary" and stays correct when the palette changes. Every role is declared twice — once on :root, .md-scheme-light and once on .md-scheme-dark.

Values are RGB channels, not finished colors, which is what lets any role be used at partial opacity without a second token per alpha value. A color token is never valid on its own; it always has to be wrapped.

Every on- role is the foreground that meets contrast requirements against the role it names, so pairing them (primary with on-primary, surface with on-surface) keeps text legible in both schemes without any per-scheme logic.

Overriding

Redeclare the roles you want after importing md3.scss, using the same selectors so source order decides. Override both blocks — changing only :root leaves dark mode on the library defaults. See getting started for the full setup.
