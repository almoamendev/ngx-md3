API

Name Type Default

List
variant

Sets the list style variant.

 input<'expressive' | 'baseline'> expressive
type

Sets the list item margins. only works with expressive variant.

 input<'standard' | 'segmented'> standard

ListItem
slots-alignment

Sets the list item slots vertical alignment.

 input<'start' | 'center' | 'end'> center
selected

List item selected state. when using selection input, the input controls selection state.

 input<boolean> false

ListLeading
type

List item leading slot type.

 input<ListLeadingType>

icon, avatar, media, selection-input

 icon
size

List item leading media size (for media type only).

 input<ListLeadingSize>

image, small-video, large-video

 image
  • When using primary and secondary actions. it is recommended to use regular list item with md3-item-primary-action inside to separate both actions entirely.
  • When using label tag as list item with selection input. it is recommended to disable input state layer.
  • Icons in leading or trailing slots should be 24dp.
  • Media inside leading slot can be an image or video in any available media size.
  • md3-icon-button can be used inside trailing slot.
