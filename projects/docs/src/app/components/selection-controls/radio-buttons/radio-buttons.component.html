Radio buttons

Radio buttons let people select one option from a set of options.

API

Name Type Default
control

Input form control object (see angular forms and form controls).

 input<AbstractControl> undefined
disable-state-layer

Disable radio button state layer.

 input<boolean> false
  • Radio button input element must have md3-input-element directive.
  • The component will be disabled when either the input element or the control is disabled.
  • When using a control object, the component will show the error state when the control has errors.
  • When using the component with an HTML input tag only (no controls), you can set the error state by adding aria-invalid="true" to the input element.
