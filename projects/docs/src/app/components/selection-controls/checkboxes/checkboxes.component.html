Checkboxes

Checkboxes let users select one or more items from a list, or turn an item on or off.

API

Name Type Default
control

Input form control object (see angular forms and form controls).

 input<AbstractControl> undefined
disable-state-layer

Disable checkbox state layer.

 input<boolean> false
  • Checkbox input element must have md3-input-element directive.
  • The component will be disabled when either the input element or the control is disabled.
  • When using a control object. the component will show error state when the control has errors.
  • When using the component with html input tag only (no controls). you can set error state by adding aria-invalid="true" to the input element
