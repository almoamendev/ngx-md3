Switches

Switches toggle the selection of an item on and off.

@if (singleIcon()) { volume_up } @if (unselectedIcon()) { close } @if (selectedIcon()) { check }

API

Name Type Default
control

Input form control object (see angular forms and form controls).

 input<AbstractControl> undefined
disable-state-layer

Disable switch state layer.

 input<boolean> false
  • Switch input element must have md3-input-element directive.
  • The component will be disabled when either the input element or the control is disabled.
  • When using a custom icon, always apply the md3-icon-element directive to the icon element.
  • Custom icons should follow the Material 3 recommended size of 16dp.
    The default md3-icon-element styles automatically set the appropriate font-size, width, and height values.
