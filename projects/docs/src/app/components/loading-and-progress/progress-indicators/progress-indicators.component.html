Progress indicators

Progress indicators show the status of a process in real time.

API

Name Type Default
indeterminate

When true, the indicator switches to an indeterminate loading animation and the progress percentage is ignored.

 input<boolean> false
thickness

Progress indicator thickness.

 input<4 | 8> 4
progress

Progress percentage (from 0 to 100). Ignored when indeterminate is true.

 input<number> 0
