Selects

A select is a text field that is picked from rather than typed into. Closed, it is the same chrome as a text field — filled or outlined, floating label, supporting text, leading and trailing icons. Open, it shows a panel of options much like a menu. It takes one value or many, and can turn its own field into a search box that filters the options as you type.

Searchable

  • Options are declared as content of the select and rendered into its panel, so they exist whether or not it is open — which is how the closed field knows what to call the value it is holding.
  • Unlike the library's other inputs, a select is bound directly: formControlName, formControl and ngModel all go on md3-select itself, because the value is not a native input's value. [control] is still accepted, but only to drive the error styling.
  • Give compare-with whenever the values are objects. Without it two structurally identical objects are different values, and nothing will look selected.
  • Never set a placeholder on a select. The text field floats its label from the input being empty, so a placeholder would leave the label floating over an empty field forever.
  • A single select closes when you pick; a multiple one stays open. Picking the option that is already selected in a single select keeps it rather than clearing the field.
  • The panel matches the field's width and follows it as the window resizes. It opens downwards, or upwards when there is no room below.
  • Opening covers the page with an invisible scrim, so the click that closes the panel does not also press whatever was underneath — the same as a native select. Clicking a neighbouring field takes a second click.
  • Keyboard: arrows, Home, End, PageUp and PageDown move through the options, Enter or Space picks, Escape closes, Tab leaves. On a select that is not searchable, typing jumps to a matching option. Focus stays in the field throughout and the active option is announced through aria-activedescendant.
  • With filter-mode="manual" the select filters nothing and just reports what was typed through (searchChange), which is what to use for a server. Pair it with [loading] and [search-debounce].
