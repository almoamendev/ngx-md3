Navigation item

Navigation items are the individual destinations projected into a navigation bar or a navigation rail. The same md3-nav-item directive works in either — see those pages for how items compose with groups, badges, and a FAB.

API

Name Type Default
hide-on-collapse

Hides the item entirely while the parent rail is collapsed.

 input<boolean> false
routerLinkActiveOptions

Forwarded from RouterLinkActive. Controls exact vs. prefix matching for the automatic active state.

 input<IsActiveMatchOptions | boolean> { exact: false }
ariaCurrentWhenActive

Forwarded from RouterLinkActive. Sets aria-current on the item when it's active.

 input<'page' | 'step' | 'location' | 'date' | 'time' | true | 'false'> 'page'
isRouteActive

Read-only. Reflects RouterLinkActive's match state. Grab it via a template reference (#item="md3NavItem") to build a custom active condition.

 boolean (getter) —
  • md3-nav-item can be applied to a <button> or an <a>.
  • When paired with routerLink, the md3-active class is applied automatically — no need to add routerLinkActive yourself. Use routerLinkActiveOptions to customize the route match, or toggle md3-active manually on an item that has no routerLink.
  • For an active condition that isn't purely route-driven, reference the item with #item="md3NavItem" and set [class.md3-active] yourself using item.isRouteActive, e.g. [class.md3-active]="item.isRouteActive && hasUnread()". This overrides the item's built-in active state.
  • Provide a filled variant of the icon with md3-icon-element="active" to swap in when the item becomes active.
  • hide-on-collapse only has an effect inside a navigation rail, since a navigation bar never collapses.
