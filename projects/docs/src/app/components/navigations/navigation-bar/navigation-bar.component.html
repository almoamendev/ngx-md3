Navigation bar

Navigation bars let people switch between UI views on smaller devices.

API

Name Type Default

NavigationBar

No configurable inputs. Its layout switches automatically between a horizontal bar on medium and expanded window sizes, and a vertical, compact bar on compact window sizes.

NavigationItem

See the navigation rail docs for its full API.

Badge

See the navigation rail docs for its full API.
  • md3-nav-item can be applied to a <button> or an <a>. Combine it with routerLink and routerLinkActive="md3-active" for automatic active-state handling, or toggle the md3-active class manually on a button.
  • Provide a filled variant of the icon with md3-icon-element="active" to swap in when the item becomes active.
  • Between 3 and 5 destinations are recommended in a navigation bar.
