FloatingActionButton

See the floating action button docs for its full API.
  • md3-nav-item can be applied to a <button> or an <a>. When paired with routerLink, the md3-active class is applied automatically — no need to add routerLinkActive yourself. Use routerLinkActiveOptions to customize the route match, or toggle md3-active manually on a button that has no routerLink.
  • For an active condition that isn't purely route-driven, reference the item with #item="md3NavItem" and set [class.md3-active] yourself using item.isRouteActive, e.g. [class.md3-active]="item.isRouteActive && hasUnread()". This overrides the item's built-in active state.
  • Provide a filled variant of the icon with md3-icon-element="active" to swap in when the item becomes active.
  • Use md3-nav-group to group related items under an optional label.
  • A single md3-fab can be placed at the top of the rail, above the navigation items.
  • Custom expand/collapse icons can be provided via md3-icon-element="expand" and md3-icon-element="collapse"; otherwise default menu icons are used.
