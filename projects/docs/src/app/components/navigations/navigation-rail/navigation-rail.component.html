Navigation rail

Navigation rails let people switch between UI views on mid-sized devices.

  • md3-nav-item can be applied to a <button> or an <a>. When paired with routerLink, the md3-active class is applied automatically — no need to add routerLinkActive yourself. Provide a filled variant of the icon with md3-icon-element="active" to swap in when the item becomes active. See the navigation item docs for customizing or overriding the active condition.
  • Use md3-nav-group to group related items under an optional label.
  • Project a md3-badge into an item to show a notification dot or a count. The rail positions it over the item's icon automatically, so no additional styling is needed.
  • A single md3-fab can be placed at the top of the rail, above the navigation items.
  • Custom expand/collapse icons can be provided via md3-icon-element="expand" and md3-icon-element="collapse"; otherwise default menu icons are used.
