  • When using a custom icon, always apply the md3-icon-element directive to the icon element.
  • Custom icons should follow the Material 3 recommended size of 18dp.
    The default md3-icon-element styles automatically set the appropriate font-size, width, and height values.
  • Filter chips support custom leading check icons.
  • Avatars are supported only in input chips. They must use the md3-chip-avatar directive and have a size of 24dp.
  • Input chips can use checkbox or radio inputs to provide selection behavior similar to filter chips.
