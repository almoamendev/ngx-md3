Sliders

Sliders allow users to make selections from a range of values.

@if (showIcon()) { volume_up }

API

Name Type Default
control

Input form control object (see angular forms and form controls).

 input<AbstractControl> undefined
slider-size

Set slider size.

 input<SliderSize>

x-small, small, medium, large, x-large

 x-small
show-value-label

Show input value when active.

 input<boolean> false
  • When using a custom icon, always apply the md3-icon-element directive to the icon element.
  • Custom icons should follow the Material 3 recommended size:
    • medium: 24dp
    • large: 24dp
    • x-large: 32dp
    The default md3-icon-element styles automatically set the appropriate font-size, width, and height values.
