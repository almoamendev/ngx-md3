  • Menus are custom components injected in the page using the menu service, anchored to a trigger element, click event or point.
  • Group related menu items with md3-menu-group. Consecutive groups render with a gap; add a md3-divider between items instead of a new group to get a divider.
  • Each menu item is a button[md3-menu-item] or a[md3-menu-item], and can optionally project a leading icon (md3-icon-element="leading"), a trailing icon (md3-icon-element="trailing") and a md3-badge.
  • Use menuService.openSubMenu() from a menu item's click handler to open a nested menu positioned beside its parent item. Sub menus always resolve xPosition to before/after (anything else falls back to after) and default overlapTrigger to true, unlike a top-level open() call.
  • While a menu is open, the trigger element gets a md3-menu-active class, useful for styling the trigger as pressed/active. Focus returns to the trigger after the menu closes.
  • Clicking the scrim or pressing Escape always closes the menu (there is no disableCloseEvents option for menus).
