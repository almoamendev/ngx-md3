Floating Action Buttons

Icon buttons help people take actions with a single tap

API

Name Type Default
button-size

Sets the button size.

 input<ButtonSize>

x-small, small, medium, large, x-large

 small
button-type

Sets the style type of the button.

 input<IconButtonType>

filled, tonal, outlined, standard

 filled
button-width

Sets the width of the button.

 input<IconButtonWidth>

default, narrow, wide

 default
button-squared

Controls button shape.

 input<boolean> false
selected

Button selection state.

 model<boolean, null> null
  • When using a custom icon. always add md3-icon-element directive to the icon element.
  • Custom icon size should follow Material 3 guidelines:
    • x-small: 20dp
    • small: 24dp
    • medium: 24dp
    • large: 32dp
    • x-large: 40dp
    Default md3-icon-element css style will set font-size, width, and height to the correct size.
