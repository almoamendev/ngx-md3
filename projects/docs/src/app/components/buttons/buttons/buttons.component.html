Buttons

Buttons prompt most actions in a UI.

API

Name Type Default
button-size

Sets the button size.

 input<ButtonSize>

x-small, small, medium, large, x-large

 small
button-type

Sets the style type of the button.

 input<ButtonType>

filled, tonal, outlined, elevated, text

 filled
button-squared

Controls button shape.

 input<boolean> false
selected

Button selection state.

 model<boolean, null> null
  • When using a custom icon, always apply the md3-icon-element directive to the icon element.
  • Custom icons should follow the Material 3 recommended size:
    • x-small: 20dp
    • small: 20dp
    • medium: 24dp
    • large: 32dp
    • x-large: 40dp
    The default md3-icon-element styles automatically set the appropriate font-size, width, and height values.
