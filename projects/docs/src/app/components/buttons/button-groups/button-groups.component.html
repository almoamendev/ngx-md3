Button groups

Button groups arrange related text and icon buttons together. They can be standard or connected, and can support no selection, single selection, or multiple selection.

API

Name Type Default
button-size
Sets the size for every button in the group.
 'x-small' | 'small' | 'medium' | 'large' | 'x-large' 'small'
group-type
Controls whether buttons are spaced as separate controls or visually connected.
 'standard' | 'connected' 'standard'
selection
Controls whether buttons behave as non-selectable, single-select, or multi-select items.
 'none' | 'single' | 'multiple' 'none'
