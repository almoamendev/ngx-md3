Button groups

Button groups arrange related text and icon buttons together. They can be standard or connected, and can support no selection, single selection, or multiple selection. When the group should not manage selection at all, the manual mode leaves every button to its own selected binding, so a single button can be a toggle while the others stay regular buttons.

In the playground, only the first button of every group is bound to selected. Switch the selection to manual to see it acting as a toggle while the remaining buttons stay regular buttons.

Button selection state. This option is controlled by the button group, unless the group selection is manual.

 model<boolean | null> null
  • none clears the selection state of every button, so none of them can be toggled.
  • single and multiple turn every button into a toggle and keep the selection in sync, ignoring the selected value each button was declared with.
  • manual hands the selection back to the buttons. A button is a toggle only when its selected value is not null, and it flips its own state on click. Buttons the group turned into toggles in another mode are released when the group switches to manual.
  • Because selected is a model, use [selected]="false" (or a two-way binding) to declare a toggle. The bare selected attribute is not a valid value.
