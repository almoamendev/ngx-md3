Floating Action Buttons

Floating action buttons (FABs) help people take primary actions.

API

Name Type Default
button-size

Sets the button size.

 input<FabSize>

small, medium, large

 small
button-type

Sets the style type of the button.

 input<FabType>

tonal-primary, tonal-secondary, tonal-tertiary, primary, secondary, tertiary

 tonal-primary
extended

Show or hide button's label.

 input<boolean> false
  • When using a custom icon. always add md3-icon-element directive to the icon element.
  • Custom icon size should follow Material 3 guidelines:
    • small: 24dp
    • medium: 28dp
    • large: 36dp
    Default md3-icon-element css style will set font-size, width, and height to the correct size;
