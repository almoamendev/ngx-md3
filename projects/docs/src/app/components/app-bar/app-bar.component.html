This demo bar reads the same LayoutService scroll signal as the rest of the site — scroll this page (not just the demo box) to see "elevate" / "auto-hide" react to the real scroll position.

App bars are placed at the top of the screen to help people navigate through a product. md3-app-bar is usually projected into a md3-scaffold's top bar region (md3-scaffold-bar="top"), and reads its scroll-elevate / auto-hide state from the scaffold's main pane via LayoutService — no extra wiring needed.

Content slots

Name Renders when
[md3-app-bar-leading] Always. Typically a menu / back icon button.
[md3-app-bar-trailing] Always. Typically icon buttons and/or an avatar.
[md3-avatar] Placed inside [md3-app-bar-trailing]; gets avatar-specific sizing/styling.
[md3-app-bar-logo] bar-type is not search, and a logo is projected — takes priority over bar-title / bar-subtitle.
[md3-search-leading], [md3-input-element], [md3-search-trailing] bar-type="search" — replaces the title/logo area with a search field.

API

Name Type Default
bar-title

Screen title. Ignored when bar-type="search" or a logo is projected.

 input<string | null> null
bar-subtitle

Optional subtitle shown under the title.

 input<string | null> null
bar-type

Small stays a fixed height; medium/large grow a second, collapsible row when there's a title or subtitle.

 input<AppBarType> small
scroll-style

How the bar reacts once the scaffold's main pane has scrolled.

 input<AppBarScrollingStyle> elevate
auto-hide

Slides the bar out of view while scrolling down, back in while scrolling up.

 input<boolean> false
center-aligned

Centers the title/logo/search field instead of aligning it to the leading edge.

 input<boolean> false
  • The bottom, collapsible title row only exists for medium / large when there's a bar-title or bar-subtitle — it grows and shrinks based on how far the scaffold's main pane has scrolled, not a fixed height.
  • Content priority for the middle area is: bar-type="search" first, then a projected [md3-app-bar-logo], then bar-title / bar-subtitle.
  • scroll-style and auto-hide both key off LayoutService.mainScrollTop(), which is populated by whichever element carries md3-scaffold-pane="main" — outside a scaffold, the bar won't react to scrolling at all.
