Dialogs

Dialogs provide important prompts in a user flow.

API

Name Type Default

interface DialogConfig<D = unknown>

injector?

Optional Angular injector used when creating the dialog component.

 Injector Injector
  • Dialogs are custom components injected in the page using dialog service.
  • When creating your custom dialog component, you can optionally use md3-dialog-header, md3-dialog-body and md3-dialog-actions.
  • On open, focus moves to the first focusable element inside the dialog (or the dialog surface itself if none is found). On close, focus returns to the element that triggered the dialog.
  • Unless disableCloseEvents is set, clicking the scrim or pressing Escape closes the dialog with no result.
