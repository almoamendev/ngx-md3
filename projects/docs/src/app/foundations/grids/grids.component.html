Grids

The responsive layout grid arranges content into a fixed number of columns that adapts to the current window size class, with margins and gutters that scale alongside it. md3-grid turns any element into the grid container; md3-grid-item marks a child and, optionally, spans it across multiple columns.

API

Name Type Default

md3-grid

Grid container. Sets display: grid and derives its column count from LayoutService.widthClass() unless overridden.

cols

Forces the column count instead of deriving it from the current window size class.

input<number | undefined> undefined

md3-grid-item

Marks a child of md3-grid and, optionally, spans it across multiple columns.

col-span

Number of columns the item spans, via grid-column: span N.

input<number> 1
  • Column count comes from the same window size classes used across the library (LayoutService.widthClass()): compact = 4, medium/expanded = 8, large/extra-large = 12.
  • Use the gear icon above the demo to force a column count and preview compact/medium-expanded/large-extra-large without resizing the window, or bind [cols] yourself the same way.
  • Margin (outer padding) and gutter (gap between columns) are exposed as the --md-grid-margin / --md-grid-gutter CSS custom properties, set per breakpoint in md-grid.scss — override them on [md3-grid] to customize spacing without touching the directive.
  • col-span is not clamped to the current column count — a large span on a narrow, low-column breakpoint will overflow into implicit grid tracks rather than shrink.
